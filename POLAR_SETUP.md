## 2. Environment Variables Added

The following environment keys are required in `.env` (names only; secrets must never be committed):

```env
POLAR_ACCESS_TOKEN=
POLAR_WEBHOOK_SECRET=
POLAR_SERVER=production
```

- `POLAR_ACCESS_TOKEN`: Organization access token created in Polar dashboard.
- `POLAR_WEBHOOK_SECRET`: Webhook endpoint secret generated by Polar for signature validation.
- `POLAR_SERVER`: `production` (default) or `sandbox`.

## 3. Provisioning & First Checkout Link

### Step A: Configure Access Token
1. Go to [Polar Organization Settings](https://polar.sh/dashboard/abdullah-bin-zafar/settings).
2. Under **Access Tokens**, generate a token with scopes:
   - `products:read`, `products:write`
   - `checkouts:read`, `checkouts:write`
   - `webhooks:read`, `webhooks:write`
3. Paste the token into `.env` as `POLAR_ACCESS_TOKEN` directly in your editor.

### Step B: Provision Product & Webhook (Automated)
Run the automated provision script from within `safemotion-ai`:
```bash
.\.venv\Scripts\python scripts/provision_polar.py
```
*(If you have a public HTTPS URL e.g. ngrok or deployed host, add `--public-url https://your-domain.com`)*.

The script will:
- Authenticate with `https://api.polar.sh/v1/products/?limit=1`.
- List active products or create a $10.00 "Test Product".
- Register the webhook endpoint if a public URL is supplied and securely update `POLAR_WEBHOOK_SECRET` in `.env`.
- Create a 100% discount code (`TEST100`) for zero-dollar checkout testing.
- Output your checkout link.

### Step C: Test Checkout
1. Start the FastAPI development server:
   ```bash
   uvicorn src.server:app --host 0.0.0.0 --port 8000 --reload
   ```
2. Open your checkout link:
   ```
   http://localhost:8000/checkout?products=<PRODUCT_ID>
   ```
3. To test end-to-end without a real charge, enter discount code `TEST100` on the Polar hosted checkout page.
